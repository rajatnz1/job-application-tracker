# Job Application Tracker

A web app for tracking job applications: company, role, status, dates, and notes.
Built to manage my own job search.

## Features (v1)
- [ ] Sign up and log in
- [ ] Add an application
- [ ] View a list of applications
- [ ] Edit and delete an application
- [ ] Change status (Wishlist, Applied, Interview, Offer, Rejected)
- [ ] Filter by status
